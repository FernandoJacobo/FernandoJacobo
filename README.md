## 💼 Experiencia destacada

### 🧾 Sistemas ERP de facturación y contabilidad electrónica (México)
Diseño y desarrollo de plataformas SaaS **multiempresa y multiusuario** para facturación **CFDI 4.0** y contabilidad electrónica.
- Complementos versionados: **Pago, Nómina, Comercio Exterior y Carta Porte**.
- Timbrado mediante integración con **PAC** externo.
- **RBAC** jerárquico (Módulo › Submódulo › Acción) administrado desde base de datos y **auditoría inmutable**.
- Aislamiento multitenant en PostgreSQL y arquitectura basada en **SOLID y Clean Code** en monorepo.
- Stack: TypeScript estricto, Next.js, NestJS, Prisma, PostgreSQL, Electron y React Native.

### 🇪🇨 Automatización y sistemas tributarios (Ecuador – SRI)
- Desarrollo de soluciones para la gestión tributaria: **retenciones de IVA**, procesos ante el **SRI** y sistemas contables.
- Automatización de la **descarga masiva de comprobantes electrónicos (XML)** del SRI.
- Desarrollo de la **landing page corporativa** para una firma de gestión de devoluciones tributarias.

### 🌐 Desarrollo web freelance
- Sitios y landing pages a medida para negocios: clínicas, empresas de servicios y eventos B2B.
- Branding visual, diseño responsive y proyectos en **WordPress** y frameworks modernos.

### 🖥️ Administración de servidores
- Configuración y mantenimiento de **VPS Linux**: usuarios, permisos, FTP (vsftpd) y despliegues.
